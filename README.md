# Супервизия 1.0

Личное приложение для задач, ежемесячного планирования и отчётности по ПСТБИ, Школам и Олимпиадам. Работает как статический сайт, без сервера и аккаунта. Данные сохраняются в localStorage текущего браузера.

## Обновление с v6

1. В старом приложении откройте «Итоги месяца» → «Выгрузка данных и резервная копия» → экспорт JSON. Сохраните файл на компьютере.
2. Распакуйте архив. Замените в корне своего существующего репозитория файлы `index.html`, `app.js`, `styles.css`, `README.md` и `.nojekyll`. Не загружайте сам ZIP вместо файлов.
3. Дождитесь завершения публикации и откройте прежний адрес приложения. Если видите старый дизайн, нажмите Ctrl+F5.
4. При том же адресе и браузере приложение использует прежнее хранилище `work-supervision-v1`. Импортировать резервную копию обычно не нужно.

В этой версии есть несколько CRM-срезов на один месяц. Старые срезы сохраняются, им добавляются внутренние идентификаторы. Даты не придумываются: запись без даты отмечена «Дата не указана». Пользовательские записи, задачи и их история не заменяются исходным примером.

Не открывайте новые данные через старые версии приложения: v6 ещё не умеет выбирать последний из нескольких срезов месяца. Перед возвратом к v6 используйте резервную копию, сделанную до обновления.

## CRM на «Обзоре»

- Блок «CRM по стадиям» показывает все 11 стадий и количество сделок.
- В списке дат выберите интересующий срез. Заголовок показывает, на какую дату приведены числа.
- «Все даты месяца» раскрывает общую таблицу для сравнения нескольких срезов.
- Δ — изменение к предыдущему по дате срезу этого месяца; если его нет, используется последний срез предыдущего месяца. Это разница количеств, а не число переходов между стадиями.
- Пустое значение означает «нет данных», а 0 — «проверено, сделок нет». Общая сумма появляется, только когда заполнены все стадии.
- Верхняя карточка CRM на «Обзоре», отчёт и аналитика всегда используют последний по дате срез месяца. Таблица ниже показывает выбранную дату.

## Как добавить срез

1. Выберите месяц вверху страницы.
2. Нажмите «Новый срез» на «Обзоре» или в разделе CRM.
3. Укажите фактическую дату внутри выбранного месяца. На одну дату допускается один срез.
4. При желании включите «Взять числа из последнего среза для сверки»; по умолчанию новый срез пустой.
5. Заполните стадии и комментарии. Изменения сохраняются после выхода из поля.

Для исправления существующей записи выберите её дату и отредактируйте поля. Для другой даты создавайте новый срез, чтобы сохранить историю. В CSV и JSON входят все даты; в месячный отчёт и аналитику — последний срез каждого месяца, даже если он пока заполнен не полностью.

## Меню и оформление

Кнопка под названием приложения сворачивает меню до значков; повторное нажатие разворачивает. Состояние сохраняется в браузере. Наведите на значок, чтобы увидеть название раздела. На узком экране меню открывается кнопкой в верхней полосе; закрывается выбором раздела, нажатием вне меню или Esc.

Весь интерфейс оформлен в светлой палитре с тёмной навигацией и бирюзовыми акцентами. Внешние шрифты, сервисы и библиотеки не загружаются.

## Проекты и шаблоны

- В «Проектах» можно создавать, редактировать и удалять пустые проекты. Изменение направления проекта обновляет все его задачи, включая исторические отчёты, а также шаблоны.
- Направления остаются фиксированными: ПСТБИ, Школы, Олимпиады. Статусы задач и CRM тоже фиксированы, чтобы сохранять сопоставимость истории.
- Откройте задачу и нажмите «В шаблоны». Шаблон содержит название, проект, планируемый результат, приоритет и признак повторения. Сроки и итоги прошлой задачи не копируются.
- При добавлении новой задачи выберите шаблон и уточните детали. Каждая новая задача получает собственный ID.
- Управление шаблонами и краткая инструкция находятся в «Настройках».

## Ежемесячный цикл

1. Соберите месяц в «Планировании» из переносов, постоянных задач и новых планов.
2. В течение месяца обновляйте задачи и создавайте срезы CRM.
3. Нажмите «Закрыть месяц»: укажите итоги и перенесите незавершённое.
4. Запишите выводы встречи в «Супервизиях».
5. Откройте «Итоги месяца», затем «Печать / PDF». В диалоге браузера выберите сохранение в PDF.
6. Скачайте резервную копию JSON. CSV задач и CRM можно выгрузить за любой диапазон месяцев.

## Хранение

Данные находятся только в этом браузере на этом устройстве. GitHub публикует код приложения, а не введённые записи. Очистка данных сайта удаляет локальные записи. JSON содержит всю базу, включая шаблоны и все CRM-срезы. Импорт заменяет текущую базу после подтверждения.
